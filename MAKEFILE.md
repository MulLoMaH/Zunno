# Makefile · Справочник команд

Все команды запускаются из корня проекта. Часть команд требует заполненного `.env` (для локальной разработки) или `.env.prod` (для продакшена).

---

## Локальная разработка

### Инфраструктура (Postgres, Redis, Kafka)

| Команда | Описание |
|---|---|
| `make env-up` | Поднять контейнеры Postgres, Redis, Kafka в фоне |
| `make env-down` | Остановить эти контейнеры (данные сохраняются) |
| `make env-cleanup` | **ОПАСНО:** удалить контейнеры + все volume-файлы (`out/pg_data`, `out/redis_data`, `out/kafka_data`). Спросит подтверждение. |

### Миграции

| Команда | Описание |
|---|---|
| `make migrate-create seq=<name>` | Создать новую пару файлов `<номер>_<name>.up.sql` и `.down.sql` в `migrations/` |
| `make migrate-up` | Применить все неприменённые миграции |
| `make migrate-down` | Откатить последнюю миграцию |
| `make migrate-force` | Выставить версию миграций в `1` и снять флаг `dirty`. Используется если миграция упала посередине |
| `make migrate-action action=<up|down|N>` | Универсальная команда. `action=up`, `action=down`, `action=down 2` (откатить 2 миграции) |

### Приложение

| Команда | Описание |
|---|---|
| `make zunno_run` | Запустить приложение локально через `go run`. Использует `.env` и `localhost`-адреса для Postgres/Redis/Kafka |
| `make test` | Прогнать все тесты с `-race` |

### Типичный сценарий локальной разработки

```bash
# 1. Поднять инфраструктуру
make env-up

# 2. Применить миграции
make migrate-up

# 3. Запустить приложение
make zunno_run

# 4. (в другом терминале) — гоняем тесты / curl
